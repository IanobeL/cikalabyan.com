JLPT Mock-Exam Platform

Kebun Academy · built for my own Japanese classes

My students were training for jobs in Japan and needed real exam practice, so I built a full JLPT simulator. It has a hidden teacher dashboard and a separate tool for writing questions. Students take timed tests, I see where they fail, and I add questions on exactly those points.

1,000N4–N3 questions in the bank
4 monthsbeginner to N3 level, Batch 2
110 → 120mock score out of 180, month 1 to month 2
3 appsstudent app, question tool, API

Features

  • Timed N5–N1 tests with reading passages and a listening audio player.
  • Results with radar charts, per-section minimum-score checks and a pass certificate.
  • Customizable teacher dashboard: test settings, student history, question publishing.
  • Question tool that converts photographed exam papers into the bank format in batches.

Architecture

  • The two front-end apps run on Google Cloud Run.
  • A separate Node.js API is the only part that holds database credentials.
  • MongoDB Atlas stores the question bank, exam histories and settings.
